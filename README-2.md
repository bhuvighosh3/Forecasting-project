# 🔮 Retail Demand Forecasting — Streamlit App

Deploys the best-per-cluster models from `Forecasting_Project_Retail.ipynb`
as an interactive Streamlit dashboard.

---

## 📁 File structure

```
your-repo/
├── app.py                   ← Streamlit dashboard
├── requirements.txt         ← pip dependencies
├── export_models.py         ← paste into notebook to export models
└── exported_models/         ← generated by running the export cell
    ├── metadata.json
    ├── prophet/
    │   ├── cluster_5.pkl
    │   ├── cluster_7.pkl
    │   └── ...
    └── neural/
        ├── cluster_0/       ← NeuralForecast .save() directory
        ├── cluster_1/
        └── ...
```

## 🚀 Step-by-step deployment

### Step 1 — Export models from your notebook

1. Open `Forecasting_Project_Retail.ipynb` in Colab (or Jupyter).
2. Run **all existing cells** through Section 11 so that these variables exist:
   - `cluster_df_dict`
   - `cluster_features`
   - `significant_features`
   - `prophet_configs`
   - `shopping_holidays`
3. Paste the contents of **`export_models.py`** into a new cell at the bottom and run it.
4. You will see an `exported_models/` folder appear in your working directory.
5. **Download** the entire `exported_models/` folder (zip it first in Colab):
   ```python
   import shutil
   shutil.make_archive("exported_models", "zip", "exported_models")
   ```
   Then right-click → Download in the Colab file browser.

### Step 2 — Set up your GitHub repo

```bash
git init retail-forecasting
cd retail-forecasting
cp /path/to/app.py .
cp /path/to/requirements.txt .
# unzip exported_models.zip here
git add .
git commit -m "initial deploy"
git remote add origin https://github.com/YOUR_USER/retail-forecasting.git
git push -u origin main
```

### Step 3 — Deploy on Streamlit Community Cloud (free)

1. Go to **https://share.streamlit.io** and sign in with GitHub.
2. Click **New app**.
3. Select your repo, branch `main`, and set **Main file path** to `app.py`.
4. Click **Deploy**.
5. Done — your app is live at `https://YOUR_USER-retail-forecasting-app-XXXX.streamlit.app`.

## 🖥️ Running locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The app opens at `http://localhost:8501`.
